# Dome Keeper mods

## Miner

A new keeper for Dome Keeper 5.0.8. Drop mines on the 1x1 tile grid (**C** / **RT**). Each mine blasts a cross through the rock and sets off any mine it reaches. The Miner has its own tech tree: more mines, longer blasts, stronger blasts, a shorter fuse, a detonator, and pickaxe, jetpack and carry upgrades.

Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3837728474

Source: `mods-unpacked/Namds-Miner/`. Packaging and upload: `workshop/`. Setup notes: `CLAUDE.md`.

This repo holds only the mod's own files. It contains no Dome Keeper game files.
